## Curriculum Rules

- Prerequisites start at `0.1` and stop before the target topic.
- Main nodes start at `1.1`.
- Each main node needs a guiding question, not only a lecture title.
- Include equations only when they support reasoning or practice.
- Include diagrams, sketches, tables, or tool checks only when they clarify the concept.

## Lesson Node Template

```markdown
**Topic:** [topic]
**Current concept:** [node]
**Learner frame:** [level/style if known]

[Two to four sentences of orientation.]

**Question:** [diagnostic or guided question]
```

## Test Rules

1. Start with one worked example.
2. Ask one question at a time.
3. Use three difficulty bands:
   - easy: familiar recall or direct application
   - medium: multi-step familiar problem
   - transfer: unfamiliar context using the same principle
4. After each answer, give correctness, reasoning feedback, one repair step, and next question or review target.

## Mastery Signals

| Signal | Evidence |
| --- | --- |
| Conceptual | Learner explains why, not only what. |
| Procedural | Learner performs steps without prompting. |
| Transfer | Learner applies the idea in a new example. |
| Metacognitive | Learner names what confused them and how they fixed it. |
