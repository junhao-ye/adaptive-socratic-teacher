# Prompt Quality Profile

## Need Model

- Explicit need: integrate two AI teacher skills into a new version.
- Implicit need: keep production readiness while improving Socratic teaching quality.
- Scenario: reusable agent skill for learners who want guided tutoring.
- Success standard: routes to teaching requests, avoids answer-only misuse, and supports plan, lesson, hint, test, and config modes.

## Quality Matrix

| Dimension | Score | Note |
| --- | ---: | --- |
| Completeness | 5/5 | Combines curriculum, dialogue, hints, assessment, and config. |
| Clarity | 5/5 | Runtime entry and references have clear routing. |
| Consistency | 4/5 | Homework support is teaching-only, not completion. |
| Practicality | 5/5 | Works without external services or scripts. |
| Specificity | 5/5 | Socratic behavior is operationalized through classifiers and ladders. |
